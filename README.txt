FORMSATHI WEBSITE SETUP

Files:
- index.html: main page content
- style.css: design and responsive layout
- script.js: WhatsApp links and year
- images/: optional images folder

HOW TO SET WHATSAPP NUMBERS:
1. Open script.js in VS Code.
2. Replace 91XXXXXXXXXX with your WhatsApp number.
3. Replace 91YYYYYYYYYY with your friend's WhatsApp number.
4. Use 91 + the 10-digit mobile number, digits only. Do not type +, spaces, or dashes.
5. Save with Ctrl+S and open index.html in a browser to test.

Example format only: 919876543210

The WhatsApp link opens a chat with a prefilled message. The visitor still has to press Send.
